# Personalized Rakhi Memory Website — Antigravity Project Skills

Copy the `.agents` directory into the root of the Antigravity project.

Expected structure:

```text
.agents/
└── skills/
    ├── rakhi-product/
    │   └── SKILL.md
    ├── 3d-memory-wall/
    │   └── SKILL.md
    └── production-quality/
        └── SKILL.md
```

## Skill responsibilities

- `rakhi-product`: product scope, UX, content, pricing, flows, privacy, URLs, analytics, and product acceptance criteria.
- `3d-memory-wall`: React Three Fiber / Three.js scene architecture, deterministic placement, threads, pins, animation, mobile behavior, accessibility, and performance.
- `production-quality`: frontend/backend architecture, payments, PostgreSQL, Cloudinary, security, analytics, deployment, testing, and release standards.

## Recommended implementation order

1. Landing + creator flow
2. Gift data model/API
3. Memory Wall
4. Payment verification
5. Public gift route
6. Admin dashboard
7. Analytics
8. Production hardening
